# Amjad Hasan Portfolio

A production-ready personal portfolio website for Amjad Hasan, built with Next.js, TypeScript, Tailwind CSS, and a responsive multi-section single-page layout.

## Features

- Dark and light theme switching with saved preference
- Responsive landing page and project detail routes
- Real project cards backed by verified public GitHub repositories
- Contact form with client-side validation and mailto fallback
- SEO metadata, social sharing metadata, and sitemap/robots routes

## Local development

```bash
npm install
npm run dev
```

Open http://localhost:3000 to view the portfolio locally.

## Production build

```bash
npm run build
npm run start
```

## Notes

- LinkedIn and WhatsApp details remain intentionally blank until verified.
- The contact form defaults to a mailto fallback until a backend email provider is configured.
- The live demo link for Expense DSS is only included because the deployment was reachable during verification.
